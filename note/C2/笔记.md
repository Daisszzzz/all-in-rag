# 1. 使用partition_pdf替换当前partition函数并分别尝试用hi_res和ocr_only进行解析，观察输出结果有何变化。
使用 hi_res 和 ocr_only 对 PDF 进行解析后，可以发现两种策略在元素数量、元素分类和文本识别结果上存在差异。hi_res 更侧重页面布局和文档结构分析，能够较好地区分 Title、NarrativeText 等元素；ocr_only 主要依赖 OCR 从页面图像中识别文字，对于扫描型 PDF 更有意义，但识别效果受 OCR 模型、语言配置和原始页面质量影响较大。本次实验中 ocr_only 对部分中文内容出现了明显误识别，因此需要正确配置中文 OCR 语言模型。
